# Contributing Guidelines
---
Thank you for your interest in contributing to the Demand Console project. We welcome all contributions and appreciate your efforts to improve our project.

## Getting Started
---
To get started with contributing to the project, please follow these steps:

1. Join the [Official Discord server](https://discord.gg/nSHPMG8zsH) to connect with the DMD community and get help with any questions you may have.

2. Visit the project's [Home page](https://github.com/blinkyboi/Demand) and familiarize yourself with the project's goals and objectives.

3. Review the [Project issues](https://github.com/blinkyboi/Demand/issues) page and find an issue that aligns with your interests and skills.

4. Fork the repository and clone it to your local machine.

5. Install any necessary dependencies and set up your development environment.

6. Make your changes and test them locally to ensure they work as expected.

7. Submit a pull request with your changes.

## Pull Request Guidelines
---
Before submitting a pull request, please make sure that:

- [ ] Your changes are consistent with the project's goals and objectives.

- [ ] Your changes are well-documented and follow the project's coding standards.

- [ ] Your changes do not introduce new bugs or break existing functionality.

- [ ] Your changes are accompanied by tests, if applicable.

- [ ] Your pull request includes a clear and concise description of the changes you have made.


Again, thank you for your interest in contributing to the Demand Console project. We appreciate your efforts to help us improve and grow our project.
